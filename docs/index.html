RRRESPONSEQ

USER GUIDE

RRRESPONSEQ IS A SEQUENCER DESIGNED FOR LIVE PERFORMANCE, BUT ALSO USEFUL AND FUN FOR CREATING WILD IDEAS IN THE STUDIO. IT'S BUILT TO REDUCE THE COMPLEXITY OF A DAW WHILE GIVING ACCESS TO EUCLIDEAN AND STOCHASTIC FUNCTIONS, DIFFERENT LENGTHS, PLAYBACK MODES, AND SOME EXPERIMENTAL IDEAS LIKE PATTERN MORPHING. IT IS CURRENTLY IN DEVELOPMENT — YOU MAY ENCOUNTER SOME ISSUES. IF YOU HAVE ANY QUESTIONS, FEEL FREE TO REACH OUT AT UGE@AZ-ROTATOR.COM.

WORKFLOW

STEP RECORD

PROGRAM NOTES AND PARAMETER LOCKS USING A MIDI KEYBOARD, ONE STEP AT A TIME. SEQUENCER MUST BE STOPPED.

EACH NOTE PLAYED RECORDS PITCH AND NOTE LENGTH AT THE CURRENT STEP, THEN ADVANCES THE CURSOR. HOLD A KEY LONGER TO RECORD A LONGER NOTE.
ACTIONRESULT
PLAY NOTERECORDS PITCH + LENGTH AT CURRENT STEP. CURSOR ADVANCES.
SHIFT + NOTESKIPS CURRENT STEP AS REST. STEP FLASHES RED. CURSOR ADVANCES.
MOVE KNOBRECORDS A P-LOCK (PER-STEP PARAMETER OVERRIDE).
CC LANE INPUTRECORDS CC VALUES FROM CONNECTED SYNTHS INTO THE ACTIVE LANE.
P-LOCKS — ANY PARAMETER CAN BE LOCKED TO A SPECIFIC VALUE FOR A SINGLE STEP. ROTATION (ROTA) MOVES P-LOCKS TOGETHER WITH THE PATTERN.
RECORDING CURSOR — WHEN THE SEQUENCER IS STOPPED, THE HIGHLIGHTED STEP IN THE GRID SHOWS EXACTLY WHERE THE NEXT NOTE WILL BE RECORDED. THE CURSOR ADVANCES AFTER EACH NOTE AND IS VISIBLE IN REAL TIME.

PATTERNS & BANKS

8 BANKS, EACH HOLDING UP TO 64 PATTERN SLOTS (8×8 GRID). USE BANKS TO ORGANISE SONG SECTIONS OR VARIATIONS.

OPERATIONHOW
OPEN BANK VIEW0 OR B — OPENS THE 8×8 SLOT GRID.
SAVE PATTERNNAVIGATE TO TARGET SLOT → Cmd+S.
LOAD PATTERNNAVIGATE TO SLOT → Enter. SWITCHES IMMEDIATELY.
DELETE SLOTDelete OR Backspace ON SELECTED SLOT.
SWITCH BANKShift+← / Shift+→ IN BANK VIEW, OR SBANK/LBANK ON CONTROLLER.
COPY PATTERNHOLD COPY ON LAUNCHPAD → TAP SOURCE PAD → TAP DESTINATION PAD.
MORPH A↔B (hardware)HOLD COPY ON LAUNCHPAD + TAP TARGET SLOT → SET B. THEN MOVE FADER 9 (CC 9) TO BLEND. TAP SAME SLOT AGAIN WITH COPY TO CANCEL.
MORPH A↔B (keyboard)IN BANK VIEW, NAVIGATE TO TARGET SLOT → C TO SET B. THEN Shift+↑ / Shift+↓ TO BLEND +5% / −5%. PRESS C ON THE SAME SLOT AGAIN TO CANCEL.
SLOTS SHOW THEIR STATUS AT A GLANCE: WHITE = HAS DATA · ORANGE = ACTIVE/LOADED · GREEN BADGE = IN CHAIN (WITH POSITION NUMBER).

PATTERN MORPHING

MORPH BLENDS ALL 8 TRACKS CONTINUOUSLY BETWEEN THE CURRENT LIVE STATE (A) AND A SAVED SLOT (B). THE BLEND IS PROBABILISTIC — AT 50% EACH STEP HAS EQUAL CHANCE OF FIRING FROM EITHER PATTERN.

STEPHOW
1. SET PATTERN BKeyboard: OPEN BANK VIEW (0), NAVIGATE TO SLOT, PRESS C. Hardware: HOLD COPY ON LAUNCHPAD + TAP PAD. THE CURRENT LIVE STATE IS FROZEN AS A, THE SLOT BECOMES B. THE DISPLAY SHOWS MORPH B → B1.3 (BANK.SLOT).
2. BLEND A→BKeyboard: Shift+↑ / Shift+↓ ADJUSTS BY +5% / −5%. WHEN MORPH B IS ACTIVE THESE KEYS CONTROL BLEND INSTEAD OF STOCHASTIC AMOUNT. Hardware: FADER 9 (CC 9) ON NANOKONTROL. 0% = ONLY A · 100% = ONLY B. THE BLEND PERCENTAGE IS SHOWN ON SCREEN.
3. CANCEL MORPHKeyboard: C ON THE SAME SLOT AGAIN IN BANK VIEW. Hardware: HOLD COPY + TAP SAME PAD.
MORPH BLENDS PATTERN PROBABILITY, NOTE, VELOCITY, GATE, AND ALL P-LOCK PARAMETERS INTERPOLATED ACROSS ALL 8 TRACKS SIMULTANEOUSLY. WHILE MORPH B IS ACTIVE, Shift+↑ / Shift+↓ CONTROL THE BLEND INSTEAD OF STOCHASTIC AMOUNT — THE SAME KEYS, CONTEXT-AWARE.

PLAY MODES

EACH TRACK CAN ADVANCE THROUGH ITS PATTERN IN A DIFFERENT WAY. MIXING MODES CREATES COMPLEX EVOLVING TEXTURES.

1
FORWARD
STANDARD LEFT-TO-RIGHT PLAYBACK. THE DEFAULT.
2
REVERSE
PLAYS THE PATTERN BACKWARDS FROM LAST STEP TO FIRST.
3
BOUNCE
ALTERNATES BETWEEN FORWARD AND REVERSE. BOUNCES AT EACH END.
4
RANDOM
EACH TICK PICKS A RANDOM STEP. FULLY STOCHASTIC PLAYBACK.
5
SNAKE
FORWARD THEN REVERSE IN A SINGLE CYCLE, SHARING END STEPS.
6
DRUNK
RANDOM WALK. EACH TICK MOVES +1 OR -1. SLOWLY DRIFTING PATTERNS.

CHAIN & MIDI EXPORT

BUILD AN ORDERED SEQUENCE OF PATTERNS AND EXPORT IT AS A STANDARD MIDI FILE — ALL 8 TRACKS, WITH NOTES, CC LANES, PROGRAM CHANGES, PITCH BEND, AND RATCHET.

BUILDING A CHAIN

OPEN BANK VIEW (0), NAVIGATE TO A SLOT AND PRESS Space TO ADD IT TO THE CHAIN. THE SLOT SHOWS A GREEN BADGE WITH ITS POSITION NUMBER. REPEAT FOR EACH SECTION IN ORDER. A SLOT CAN APPEAR MULTIPLE TIMES.

ACTIONRESULT
Space ON FILLED SLOTADDS SLOT TO END OF CHAIN. IF ALREADY IN CHAIN, REMOVES LAST OCCURRENCE.
XCLEARS THE ENTIRE CHAIN.
F OVER TARGET SLOTFLATTENS THE ENTIRE CHAIN INTO THAT SLOT — CONCATENATES ALL PATTERNS INTO ONE LONG PATTERN AND LOADS IT IMMEDIATELY. THE CHAIN IS THEN CLEARED. MAX 8 SLOTS.
GREEN BADGE ON SLOTSHOWS POSITION(S) OF THAT SLOT IN THE CHAIN (E.G. "1", "3", "1,4").
THE CHAIN ALSO DRIVES LIVE PLAYBACK — THE SEQUENCER ADVANCES TO THE NEXT SLOT AUTOMATICALLY WHEN THE CURRENT PATTERN COMPLETES.
FLATTEN SUPPORTS UP TO 8 SLOTS — 8×64 STEPS = 512-STEP PATTERN, NAVIGABLE VIA Q/W (STEP PAGE ±). THE CHAIN CAN BE LONGER THAN 8 SLOTS FOR LIVE PLAYBACK, BUT FLATTEN REQUIRES ≤ 8.
THE CHAIN IS SAVED WITH THE SESSION — IT SURVIVES APP RESTARTS.

MIDI EXPORT

WITH A CHAIN BUILT, PRESS E. DOWNLOADS A TYPE-1 MIDI FILE (8 TRACKS, 480 PPQ).

WHAT IS EXPORTEDDETAIL
NOTESALL ACTIVE STEPS — FROM P-LOCKS, TONAL MELODY, OR ROOT NOTE.
NOTE LENGTH & GATEPER-STEP LENGTHS PRESERVED EXACTLY.
RATCHETMULTIPLE NOTE-ON/OFF EVENTS PER STEP WITH CORRECT SPREAD AND VELOCITY CURVE.
SWINGTIMING OFFSET APPLIED TO EVERY OTHER STEP.
CC LANESALL 8 CC LANES PER TRACK — VALUES FROM P-LOCKS WRITTEN AS CC EVENTS.
PROGRAM CHANGESENT AT THE START OF EACH SLOT IF ENABLED. P-LOCK PCS ALSO INCLUDED.
PITCH BEND & AFTERTOUCHPER-STEP VALUES FROM STEP RECORD.
TEMPOONE TEMPO META EVENT PER SLOT — EACH SLOT CAN HAVE ITS OWN BPM.
MUTED TRACKSEXCLUDED FROM MIDI OUTPUT.
THE FILE IS COMPATIBLE WITH ANY DAW (ABLETON, LOGIC, BITWIG…). IMPORT IT AS MIDI CLIPS TO CONTINUE EDITING.
